# Kitchen Flex

Flexbox practice game - Assignment 2.

Arrange the ingredients on the tray to match the instruction shown for each level, by changing the tray's flex-direction, flex-wrap, justify-content and align-items with the dropdowns. Click "Check Solution" to see if you got it right.

## How to play

* Read the instruction at the top of the board.
* Change the four dropdowns until you think the layout matches.
* Click Check Solution.
* If it's wrong, keep trying. If it's right, click Next Level.
* Reset Level puts the dropdowns back to their starting values.
* You can click on any level number you already finished to go back to it.

8 levels total, some need more than one property changed at once, and one level needs flex-wrap.

## Files

* index.html
* style.css
* script.js

No frameworks, no JS libraries, no CSS grid - just HTML/CSS/JS.

## Running it

Just open index.html in a browser. Progress is saved in localStorage so it's still there if you refresh.
